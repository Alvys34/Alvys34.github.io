# Giacomo Ponzi portfolio

A plain static portfolio site prepared for GitHub Pages. No framework or build step is required.

## Update content

Edit `assets/content.js` to change project cards, blog posts, labels, descriptions, and the placeholder email address. Each individual project/article page gets its content from that file.

## Publish on GitHub Pages

1. Create a **public** repository named `<your-github-username>.github.io`.
2. Upload the contents of this folder to the repository root.
3. In the repository, open **Settings → Pages**, choose **Deploy from a branch**, then select `main` and the root folder.
4. The site will be served at `https://<your-github-username>.github.io/` once GitHub finishes publishing it.

For a project repository instead, GitHub Pages will serve it at `https://<your-github-username>.github.io/<repository-name>/`; the links in this first version assume the user-site setup above.
